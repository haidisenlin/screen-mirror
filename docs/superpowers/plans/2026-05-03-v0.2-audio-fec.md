# v0.2 Audio + FEC + Sync Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add system audio streaming (Opus), forward error correction (XOR FEC), audio jitter buffer, and audio-video synchronization to the existing v0.1 video pipeline.

**Architecture:** ScreenCaptureKit provides both audio and video callbacks with shared presentationTimeStamp. Audio is Opus-encoded and sent as separate RTP stream (PT=111). Both streams get per-frame XOR FEC protection (PT=127). Receiver demuxes by PT, recovers lost packets via FEC, decodes audio with Opus (PLC on loss), buffers in 40ms ring buffer, outputs via CoreAudio AudioUnit. Sync uses audio-master clock with ±2% resampling drift correction.

**Tech Stack:** Rust, Opus (audiopus crate), CoreAudio (raw FFI), ScreenCaptureKit (screencapturekit crate), XOR FEC (custom implementation).

// src/transport/fec.rs
use super::rtp::{RtpHeader, RtpPacket};

#[derive(Debug, Clone)]
pub struct FecHeader {
    pub base_seq: u16,
    pub group_len: u8,
    pub media_pt: u8,
}

impl FecHeader {
    pub fn serialize(&self) -> [u8; 4] {
        let mut buf = [0u8; 4];
        buf[0..2].copy_from_slice(&self.base_seq.to_be_bytes());
        buf[2] = self.group_len;
        buf[3] = self.media_pt;
        buf
    }

    pub fn parse(buf: &[u8]) -> Option<Self> {
        if buf.len() < 4 {
            return None;
        }
        Some(Self {
            base_seq: u16::from_be_bytes([buf[0], buf[1]]),
            group_len: buf[2],
            media_pt: buf[3],
        })
    }
}

pub struct FecEncoder {
    group_size: usize,
    media_pt: u8,
    buffer: Vec<RtpPacket>,
    base_seq: u16,
    fec_seq: u16,
    ssrc: u32,
}

impl FecEncoder {
    pub fn new(group_size: usize, media_pt: u8) -> Self {
        Self {
            group_size,
            media_pt,
            buffer: Vec::with_capacity(group_size),
            base_seq: 0,
            fec_seq: 0,
            ssrc: rand_ssrc(),
        }
    }

    pub fn push(&mut self, pkt: &RtpPacket) -> Option<RtpPacket> {
        if self.buffer.is_empty() {
            self.base_seq = pkt.header.sequence_number;
        }
        self.buffer.push(pkt.clone());

        if self.buffer.len() >= self.group_size {
            let fec = self.generate_fec();
            self.buffer.clear();
            Some(fec)
        } else {
            None
        }
    }

    pub fn flush(&mut self) -> Option<RtpPacket> {
        if self.buffer.is_empty() {
            return None;
        }
        let fec = self.generate_fec();
        self.buffer.clear();
        Some(fec)
    }

    fn generate_fec(&mut self) -> RtpPacket {
        let max_len = self.buffer.iter().map(|p| p.payload.len()).max().unwrap_or(0);
        let mut xor_payload = vec![0u8; max_len];

        for pkt in &self.buffer {
            for (i, &b) in pkt.payload.iter().enumerate() {
                xor_payload[i] ^= b;
            }
        }

        let fec_header = FecHeader {
            base_seq: self.base_seq,
            group_len: self.buffer.len() as u8,
            media_pt: self.media_pt,
        };

        let mut payload = Vec::with_capacity(4 + xor_payload.len());
        payload.extend_from_slice(&fec_header.serialize());
        payload.extend_from_slice(&xor_payload);

        let seq = self.fec_seq;
        self.fec_seq = self.fec_seq.wrapping_add(1);

        RtpPacket {
            header: RtpHeader {
                version: 2,
                padding: false,
                extension: false,
                marker: false,
                payload_type: 127,
                sequence_number: seq,
                timestamp: self.buffer.last().map(|p| p.header.timestamp).unwrap_or(0),
                ssrc: self.ssrc,
            },
            payload,
        }
    }
}

pub struct FecDecoder {
    groups: Vec<FecGroup>,
}

struct FecGroup {
    base_seq: u16,
    group_len: u8,
    packets: Vec<Option<RtpPacket>>,
    fec_payload: Option<Vec<u8>>,
}

impl FecDecoder {
    pub fn new() -> Self {
        Self { groups: Vec::new() }
    }

    pub fn push_media(&mut self, pkt: &RtpPacket) {
        for group in &mut self.groups {
            let seq = pkt.header.sequence_number;
            let offset = seq.wrapping_sub(group.base_seq) as usize;
            if offset < group.group_len as usize {
                group.packets[offset] = Some(pkt.clone());
            }
        }
    }

    pub fn push_fec(&mut self, pkt: &RtpPacket) {
        if pkt.payload.len() < 4 {
            return;
        }
        let header = match FecHeader::parse(&pkt.payload[..4]) {
            Some(h) => h,
            None => return,
        };
        let fec_payload = pkt.payload[4..].to_vec();
        let mut packets = Vec::with_capacity(header.group_len as usize);
        packets.resize_with(header.group_len as usize, || None);

        self.groups.push(FecGroup {
            base_seq: header.base_seq,
            group_len: header.group_len,
            packets,
            fec_payload: Some(fec_payload),
        });
    }

    pub fn recover(&mut self, missing_seq: u16) -> Option<Vec<u8>> {
        let group_idx = self.groups.iter().position(|g| {
            let offset = missing_seq.wrapping_sub(g.base_seq) as usize;
            offset < g.group_len as usize
        })?;

        let group = &self.groups[group_idx];
        let offset = missing_seq.wrapping_sub(group.base_seq) as usize;

        if group.packets[offset].is_some() {
            return None; // not actually missing
        }

        let fec_payload = group.fec_payload.as_ref()?;

        // Check exactly one packet is missing
        let missing_count = group.packets.iter().filter(|p| p.is_none()).count();
        if missing_count != 1 {
            return None;
        }

        // XOR all present payloads with FEC to recover missing
        let mut recovered = fec_payload.clone();
        for pkt in group.packets.iter().flatten() {
            for (i, &b) in pkt.payload.iter().enumerate() {
                if i < recovered.len() {
                    recovered[i] ^= b;
                }
            }
        }

        Some(recovered)
    }

    pub fn remove_old_groups(&mut self, before_seq: u16) {
        self.groups.retain(|g| {
            let end_seq = g.base_seq.wrapping_add(g.group_len as u16);
            end_seq.wrapping_sub(before_seq) < 32768
        });
    }
}

fn rand_ssrc() -> u32 {
    use std::time::{SystemTime, UNIX_EPOCH};
    let t = SystemTime::now().duration_since(UNIX_EPOCH).unwrap_or_default();
    (t.as_nanos() & 0xFFFFFFFF) as u32 ^ 0xFEC0FEC0
}

// src/transport/jitter.rs
use std::collections::VecDeque;

pub struct AudioJitterBuffer {
    frames: VecDeque<Vec<f32>>,
    capacity: usize,
}

impl AudioJitterBuffer {
    pub fn new(capacity: usize) -> Self {
        Self {
            frames: VecDeque::with_capacity(capacity),
            capacity,
        }
    }

    pub fn push_frame(&mut self, samples: &[f32]) {
        if self.frames.len() >= self.capacity {
            self.frames.pop_front(); // drop oldest
        }
        self.frames.push_back(samples.to_vec());
    }

    pub fn pull_frame(&mut self, out: &mut [f32]) -> bool {
        match self.frames.pop_front() {
            Some(frame) => {
                let copy_len = out.len().min(frame.len());
                out[..copy_len].copy_from_slice(&frame[..copy_len]);
                if copy_len < out.len() {
                    out[copy_len..].fill(0.0);
                }
                true
            }
            None => false,
        }
    }

    pub fn level(&self) -> usize {
        self.frames.len()
    }

    pub fn is_empty(&self) -> bool {
        self.frames.is_empty()
    }

    pub fn clear(&mut self) {
        self.frames.clear();
    }
}

pub struct SyncState {
    audio_samples_played: u64,
    last_video_rtp_ts: u32,
    drift_samples: i64,
    rate_adjustment: f64,
}

impl SyncState {
    pub fn new() -> Self {
        Self {
            audio_samples_played: 0,
            last_video_rtp_ts: 0,
            drift_samples: 0,
            rate_adjustment: 1.0,
        }
    }

    pub fn rate_adjustment(&self) -> f64 {
        self.rate_adjustment
    }

    pub fn report_audio_played(&mut self, samples: u64) {
        self.audio_samples_played = samples;
    }

    pub fn report_video_rendered(&mut self, rtp_ts: u32) {
        self.last_video_rtp_ts = rtp_ts;
        self.update_drift();
    }

    fn update_drift(&mut self) {
        let audio_time_ms = (self.audio_samples_played * 1000) / 48000;
        let video_time_ms = (self.last_video_rtp_ts as u64 * 1000) / 90000;

        if audio_time_ms == 0 || video_time_ms == 0 {
            return;
        }

        let drift_ms = video_time_ms as i64 - audio_time_ms as i64;
        self.drift_samples = drift_ms * 48; // samples at 48kHz

        if drift_ms > 30 {
            self.rate_adjustment = 1.02; // speed up audio
        } else if drift_ms < -30 {
            self.rate_adjustment = 0.98; // slow down audio
        } else if drift_ms.unsigned_abs() < 10 {
            self.rate_adjustment = 1.0;
        }
    }
}

            1 => Channels::Mono,
            2 => Channels::Stereo,

        };

        let decoder = Decoder::new(sample_rate, channels)?;
        let frame_size = (config.sample_rate * config.frame_duration_ms / 1000) as usize
            * config.channels as usize;

        Ok(Self {
            decoder,
            frame_size,
            channels: config.channels,
            decode_buf: vec![0.0f32; frame_size],
        })
    }

    pub fn decode(&mut self, opus_data: &[u8]) -> Result<&[f32]> {
        let samples = self.decoder.decode_float(
            Some(opus_data),
            &mut self.decode_buf,
            false,
        )?;
        Ok(&self.decode_buf[..samples * self.channels as usize])
    }

    pub fn decode_plc(&mut self) -> Result<&[f32]> {
        let samples = self.decoder.decode_float(
            None,
            &mut self.decode_buf,
            false,
        )?;
        Ok(&self.decode_buf[..samples * self.channels as usize])
    }

    pub fn frame_size_samples(&self) -> usize {
        self.frame_size
    }
}

const K_AUDIO_FORMAT_LINEAR_PCM: u32 = u32::from_be_bytes(*b"lpcm");
const K_AUDIO_FORMAT_FLAG_IS_FLOAT: u32 = 1;

struct CallbackState {
    jitter_buffer: Arc<Mutex<AudioJitterBuffer>>,
    frame_buf: Vec<f32>,
    samples_played: u64,
}

pub struct AudioOutput {
    unit: AudioUnit,
    _state: Box<CallbackState>,
    jitter_buffer: Arc<Mutex<AudioJitterBuffer>>,
    samples_played: Arc<Mutex<u64>>,
}

unsafe extern "C" fn render_callback(
    in_ref_con: *mut c_void,
    _io_action_flags: *mut u32,
    _in_time_stamp: *const AudioTimeStamp,
    _in_bus_number: u32,
    in_number_frames: u32,
    io_data: *mut AudioBufferList,
) -> OSStatus {
    let state = &mut *(in_ref_con as *mut CallbackState);
    let needed = in_number_frames as usize * 2; // stereo

    let buf_list = &mut *io_data;
    let audio_buf = &mut buf_list.buffers[0];
    let out_ptr = audio_buf.data as *mut f32;
    let out_slice = std::slice::from_raw_parts_mut(out_ptr, needed);

    let mut jb = state.jitter_buffer.lock().unwrap();

    // Pull frames from jitter buffer to fill output
    let mut offset = 0;
    while offset < needed {
        let remaining = needed - offset;
        let frame_samples = 960.min(remaining); // 480 samples * 2 channels = 960
        if state.frame_buf.len() < frame_samples {
            state.frame_buf.resize(frame_samples, 0.0);
        }
        if jb.pull_frame(&mut state.frame_buf[..frame_samples]) {
            out_slice[offset..offset + frame_samples]
                .copy_from_slice(&state.frame_buf[..frame_samples]);
        } else {
            // underrun: silence
            out_slice[offset..offset + frame_samples].fill(0.0);
        }
        offset += frame_samples;
    }

    state.samples_played += in_number_frames as u64;
    0
}

impl AudioOutput {
    pub fn new(jitter_buffer: Arc<Mutex<AudioJitterBuffer>>) -> Result<Self> {
        let desc = AudioComponentDescription {
            component_type: K_AUDIO_UNIT_TYPE_OUTPUT,
            component_sub_type: K_AUDIO_UNIT_SUB_TYPE_DEFAULT_OUTPUT,

        let status = unsafe { AudioComponentInstanceNew(component, &mut unit) };
        if status != 0 {
            anyhow::bail!("AudioComponentInstanceNew failed: {status}");
        }

        // Set stream format: Float32, 48kHz, Stereo, interleaved
        let format = AudioStreamBasicDescription {
            sample_rate: 48000.0,
            format_id: K_AUDIO_FORMAT_LINEAR_PCM,
            format_flags: K_AUDIO_FORMAT_FLAG_IS_FLOAT | K_AUDIO_FORMAT_FLAG_IS_PACKED,
            bytes_per_packet: 8, // 2 channels * 4 bytes
            frames_per_packet: 1,
            bytes_per_frame: 8,
            channels_per_frame: 2,
            bits_per_channel: 32,
            reserved: 0,
        };

        let status = unsafe {
            AudioUnitSetProperty(
                unit,
                K_AUDIO_UNIT_PROPERTY_STREAM_FORMAT,
                K_AUDIO_OUTPUT_UNIT_SCOPE,
                0,
                &format as *const _ as *const c_void,
                std::mem::size_of::<AudioStreamBasicDescription>() as u32,
            )
        };
        if status != 0 {
            anyhow::bail!("set stream format failed: {status}");
        }

        let state = Box::new(CallbackState {
            jitter_buffer: Arc::clone(&jitter_buffer),
            frame_buf: vec![0.0f32; 960],
            samples_played: 0,
        });

        let callback = AURenderCallbackStruct {
            input_proc: render_callback,
            input_proc_ref_con: &*state as *const CallbackState as *mut c_void,
        };

        let status = unsafe {
            AudioUnitSetProperty(
                unit,
                K_AUDIO_UNIT_PROPERTY_SET_RENDER_CALLBACK,
                K_AUDIO_OUTPUT_UNIT_SCOPE,
                0,
                &callback as *const _ as *const c_void,
                std::mem::size_of::<AURenderCallbackStruct>() as u32,
            )
        };
        if status != 0 {
            anyhow::bail!("set render callback failed: {status}");
        }

        let status = unsafe { AudioUnitInitialize(unit) };
        if status != 0 {
            anyhow::bail!("AudioUnitInitialize failed: {status}");
        }

        let status = unsafe { AudioOutputUnitStart(unit) };
        if status != 0 {
            anyhow::bail!("AudioOutputUnitStart failed: {status}");
        }

        Ok(Self {
            unit,
            _state: state,
            jitter_buffer,
            samples_played: Arc::new(Mutex::new(0)),
        })
    }

    pub fn jitter_buffer(&self) -> &Arc<Mutex<AudioJitterBuffer>> {
        &self.jitter_buffer
    }
}

    }

// src/bin/sender.rs
use anyhow::Result;
use std::net::SocketAddr;
use tracing_subscriber::EnvFilter;

use screen_mirror::audio::opus_encoder::OpusEncoder;
use screen_mirror::audio::AudioConfig;
use screen_mirror::capture::macos::MacOsCapture;
use screen_mirror::capture::CaptureConfig;
use screen_mirror::encode::videotoolbox::VTEncoder;
use screen_mirror::encode::EncoderConfig;
use screen_mirror::transport::fec::FecEncoder;
use screen_mirror::transport::rtp::{H264Packetizer, RtpHeader, RtpPacket};
use screen_mirror::transport::udp::UdpSender;

fn main() -> Result<()> {
    tracing_subscriber::fmt()
        .with_env_filter(EnvFilter::from_default_env())
        .init();

    let target: SocketAddr = std::env::args()
        .nth(1)
        .unwrap_or_else(|| "127.0.0.1:5004".to_string())
        .parse()?;

    tracing::info!("sender starting, target={target}");

    let capture = MacOsCapture::new(&CaptureConfig {
        fps: 60,
        width: 0,
        height: 0,
        capture_audio: true,
    })?;

    let cap_w = capture.width();
    let cap_h = capture.height();
    let pixels = cap_w as u64 * cap_h as u64;
    let bitrate = (pixels * 10_000_000 / (1920 * 1080)) as u32;
    tracing::info!("capturing at {cap_w}x{cap_h}, bitrate={bitrate}");

    let mut encoder = VTEncoder::new(&EncoderConfig {
        width: cap_w,
        height: cap_h,
        fps: 60,
        bitrate,
    })?;

    let audio_config = AudioConfig {
        sample_rate: 48000,
        channels: 2,
        bitrate: 128000,
        frame_duration_ms: 10,
    };
    let mut audio_encoder = OpusEncoder::new(&audio_config)?;

    let mut video_packetizer = H264Packetizer::new(96, 0x12345678, 1400);
    let mut video_fec = FecEncoder::new(6, 96);
    let mut audio_fec = FecEncoder::new(6, 111);
    let mut audio_seq: u16 = 0;
    let audio_ssrc: u32 = 0x87654321;

    let udp = UdpSender::new(target)?;

    let mut frame_count: u64 = 0;
    let mut audio_pcm_buf: Vec<f32> = Vec::new();
    let frame_size_samples = audio_config.frame_size(); // 960 for stereo 10ms

    loop {
        // Video capture + encode
        let Some(sample) = capture.next_frame() else {
            continue;
        };

        let Some(pixel_buffer) = sample.image_buffer() else {
            continue;
        };

        let ts_ns = sample.display_time().unwrap_or_else(|| {
            let t = sample.presentation_timestamp();
            (t.value as u64 * 1_000_000_000) / t.timescale as u64
        });

        encoder.encode_pixel_buffer(pixel_buffer.as_ptr(), ts_ns)?;
        frame_count += 1;

        if frame_count.is_multiple_of(60) {
            tracing::info!("encoded {frame_count} frames");
        }

        // Send encoded video with FEC
        while let Some(encoded) = encoder.next_encoded() {
            let rtp_ts = (encoded.timestamp / 11_111) as u32;
            for nal in &encoded.nal_units {
                let rtp_packets = video_packetizer.packetize(nal, rtp_ts);
                for pkt in &rtp_packets {
                    udp.send(&pkt.serialize())?;
                    if let Some(fec_pkt) = video_fec.push(pkt) {
                        udp.send(&fec_pkt.serialize())?;
                    }
                }
            }
            // Flush FEC at frame boundary
            if let Some(fec_pkt) = video_fec.flush() {
                udp.send(&fec_pkt.serialize())?;
            }
        }

        // Audio: drain any available audio samples
        while let Some(audio_sample) = capture.try_next_audio() {
            if let Some(pcm_data) = extract_audio_pcm(&audio_sample) {
                audio_pcm_buf.extend_from_slice(&pcm_data);

                while audio_pcm_buf.len() >= frame_size_samples {
                    let frame: Vec<f32> =
                        audio_pcm_buf.drain(..frame_size_samples).collect();

                    let opus_data = audio_encoder.encode(&frame)?;
                    let audio_rtp_ts =
                        (ts_ns as u64 * 48000 / 1_000_000_000) as u32;

                    let audio_pkt = RtpPacket {
                        header: RtpHeader {
                            version: 2,
                            padding: false,
                            extension: false,
                            marker: true,
                            payload_type: 111,
                            sequence_number: audio_seq,
                            timestamp: audio_rtp_ts,
                            ssrc: audio_ssrc,
                        },
                        payload: opus_data.to_vec(),
                    };
                    audio_seq = audio_seq.wrapping_add(1);

                    udp.send(&audio_pkt.serialize())?;
                    if let Some(fec_pkt) = audio_fec.push(&audio_pkt) {
                        udp.send(&fec_pkt.serialize())?;
                    }
                }
            }
        }
    }
}

fn extract_audio_pcm(sample: &screencapturekit::cm::CMSampleBuffer) -> Option<Vec<f32>> {
    // ScreenCaptureKit delivers audio as Float32 interleaved PCM in CMSampleBuffer.
    // Extract via CMSampleBufferGetAudioBufferListWithRetainedBlockBuffer or
    // raw pointer access to the data buffer.
    // For now, use the screencapturekit crate's audio_buffers() API if available,
    // otherwise access raw CMBlockBuffer data.
    let audio_bufs = sample.audio_buffers()?;
    if audio_bufs.is_empty() {
        return None;
    }
    // Combine all audio buffer data into f32 samples
    let mut pcm = Vec::new();
    for buf in &audio_bufs {
        let data = buf.data();
        let floats: &[f32] = unsafe {
            std::slice::from_raw_parts(data.as_ptr() as *const f32, data.len() / 4)
        };
        pcm.extend_from_slice(floats);
    }
    if pcm.is_empty() { None } else { Some(pcm) }
}

impl App {
    fn poll_packets(&mut self) {
        loop {
            match self.udp.recv(&mut self.recv_buf) {
                Ok(n) => {
                    let Some(pkt) = RtpPacket::parse(&self.recv_buf[..n]) else {
                        continue;
                    };

                    match pkt.header.payload_type {
                        96 => self.handle_video_packet(&pkt),
                        111 => self.handle_audio_packet(&pkt),
                        127 => self.handle_fec_packet(&pkt),
                        _ => {}
                    }
                }
                Err(e) => {
                    match e.downcast_ref::<std::io::Error>() {
                        Some(io_err)
                            if io_err.kind() == std::io::ErrorKind::WouldBlock =>
                        {
                            break;
                        }
                        _ => {
                            tracing::error!("recv error: {e}");
                            break;
                        }
                    }
                }
            }
        }
    }

    fn handle_video_packet(&mut self, pkt: &RtpPacket) {
        // Check for loss
        if let Some(prev) = self.last_video_seq {
            let expected = prev.wrapping_add(1);
            if pkt.header.sequence_number != expected {
                // Try FEC recovery
                let mut seq = expected;
                while seq != pkt.header.sequence_number {
                    if let Some(recovered_payload) = self.video_fec.recover(seq) {
                        let recovered_pkt = RtpPacket {
                            header: RtpPacket::parse(&self.recv_buf[..12])
                                .map(|p| p.header)
                                .unwrap_or(pkt.header.clone()),
                            payload: recovered_payload,
                        };
                        self.video_fec.push_media(&recovered_pkt);
                        self.feed_video_depacketizer(&recovered_pkt);
                        tracing::debug!("FEC recovered video seq={seq}");
                    } else {
                        tracing::warn!("video loss: seq={seq} unrecoverable");
                    }
                    seq = seq.wrapping_add(1);
                }
            }
        }
        self.last_video_seq = Some(pkt.header.sequence_number);
        self.video_fec.push_media(pkt);
        self.feed_video_depacketizer(pkt);
    }

    fn feed_video_depacketizer(&mut self, pkt: &RtpPacket) {
        let marker = pkt.header.marker;
        let ts = pkt.header.timestamp as u64;
        self.depacketizer.push(pkt);

        if marker {
            if let Some(nal) = self.depacketizer.pop_nal() {
                if let Err(e) = self.decoder.decode_nal(&nal, ts) {
                    tracing::warn!("decode error: {e}");
                }
            }
        }
    }

    fn handle_audio_packet(&mut self, pkt: &RtpPacket) {
        // Check for loss
        if let Some(prev) = self.last_audio_seq {
            let expected = prev.wrapping_add(1);
            if pkt.header.sequence_number != expected {
                let mut seq = expected;
                while seq != pkt.header.sequence_number {
                    if let Some(recovered_payload) = self.audio_fec.recover(seq) {
                        self.decode_audio_payload(&recovered_payload);
                        tracing::debug!("FEC recovered audio seq={seq}");
                    } else {
                        // PLC
                        if let Ok(plc_pcm) = self.audio_decoder.decode_plc() {
                            let mut jb = self.jitter_buffer.lock().unwrap();
                            jb.push_frame(plc_pcm);
                        }
                    }
                    seq = seq.wrapping_add(1);
                }
            }
        }
        self.last_audio_seq = Some(pkt.header.sequence_number);
        self.audio_fec.push_media(pkt);
        self.decode_audio_payload(&pkt.payload);
    }

    fn decode_audio_payload(&mut self, opus_data: &[u8]) {
        match self.audio_decoder.decode(opus_data) {
            Ok(pcm) => {
                let mut jb = self.jitter_buffer.lock().unwrap();
                jb.push_frame(pcm);
            }
            Err(e) => tracing::warn!("opus decode error: {e}"),
        }
    }

    fn handle_fec_packet(&mut self, pkt: &RtpPacket) {
        if pkt.payload.len() < 4 {
            return;
        }
        if let Some(header) = FecHeader::parse(&pkt.payload[..4]) {
            match header.media_pt {
                96 => self.video_fec.push_fec(pkt),
                111 => self.audio_fec.push_fec(pkt),
                _ => {}
            }
        }
    }

    fn render_video(&mut self) {
        if let Some(frame) = self.decoder.next_frame() {
            if let Some(renderer) = &mut self.renderer {
                let _ = unsafe { renderer.render_pixel_buffer(frame.pixel_buffer) };
                self.frames_rendered += 1;
                self.sync_state.report_video_rendered(frame.timestamp as u32);
                if self.frames_rendered.is_multiple_of(60) {
                    tracing::info!("rendered {} frames", self.frames_rendered);
                }
            }
        }
    }
}

fn main() -> Result<()> {
    tracing_subscriber::fmt()
        .with_env_filter(EnvFilter::from_default_env())
        .init();

    let bind: SocketAddr = std::env::args()
        .nth(1)
        .unwrap_or_else(|| "0.0.0.0:5004".to_string())
        .parse()?;

    tracing::info!("receiver starting, listening on {bind}");

    let udp = UdpReceiver::new(bind)?;
    udp.set_nonblocking(true)?;

    let decoder = VTDecoder::new(DecoderConfig {
        width: 1920,
        height: 1080,
    })?;

    let audio_config = AudioConfig {
        sample_rate: 48000,
        channels: 2,
        bitrate: 128000,
        frame_duration_ms: 10,
    };
    let audio_decoder = OpusDecoder::new(&audio_config)?;
    let jitter_buffer = Arc::new(Mutex::new(AudioJitterBuffer::new(4))); // 40ms

    let mut app = App {
        window: None,
        renderer: None,
        udp,
        depacketizer: H264Depacketizer::new(),
        decoder,
        audio_decoder,
        audio_output: None,
        jitter_buffer,
        video_fec: FecDecoder::new(),
        audio_fec: FecDecoder::new(),
        sync_state: SyncState::new(),
        recv_buf: vec![0u8; 65536],
        last_video_seq: None,
        last_audio_seq: None,
        frames_rendered: 0,
    };

    let event_loop = EventLoop::new()?;
    event_loop.run_app(&mut app)?;

    Ok(())
}

## Notes for Implementer

1. **screencapturekit crate audio API**: The `CMSampleBuffer` audio extraction in `extract_audio_pcm` may need adjustment. Check if the crate provides `.audio_buffers()` or if you need raw FFI to `CMSampleBufferGetAudioBufferListWithRetainedBlockBuffer`. The audio format from ScreenCaptureKit is typically Float32 interleaved at the device's native sample rate (usually 48kHz).

2. **audiopus crate**: If `audiopus` doesn't compile or has API differences, `magnum-opus` is the alternative (used by RustDesk). The API is similar: `Encoder::new(sample_rate, channels, application)` → `.encode_float(pcm, output)`.

3. **CoreAudio FFI**: The AudioUnit types and constants may need fine-tuning. The `AudioComponentDescription` fourcc values are big-endian on macOS. If `AudioComponentFindNext` returns null, try `kAudioUnitSubType_HALOutput` instead of `kAudioUnitSubType_DefaultOutput`.

4. **FEC group at frame boundary**: The sender flushes video FEC at each frame end (after all NAL packets are sent). This ensures FEC groups align with frame boundaries per the design spec.

5. **Sync drift**: On first run, drift correction may not be needed (LAN <1ms). The sync module tracks drift but only applies correction when |drift| > 30ms. If testing shows consistent drift, the resampling correction (±2%) will gradually pull audio back into alignment.

6. **Audio capture permissions**: ScreenCaptureKit audio capture may require additional TCC permissions on macOS. If audio callbacks don't fire, check System Preferences → Privacy & Security → Screen Recording (same permission covers audio).
