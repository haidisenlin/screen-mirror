# v0.1 Minimal Video Pipeline (macOS → macOS) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a minimal end-to-end video streaming pipeline: macOS screen capture → H.264 hardware encode → RTP/UDP send → receive → H.264 hardware decode → Metal render in a window.

**Architecture:** Two binaries (sender + receiver) communicating over localhost/LAN via RTP/UDP. Sender captures screen with ScreenCaptureKit, encodes with VideoToolbox, packs into RTP and sends. Receiver unpacks RTP, decodes with VideoToolbox, renders to a Metal-backed window via winit.

**Tech Stack:** Rust, ScreenCaptureKit (via screencapturekit-rs), VideoToolbox (via FFI with objc2), Metal (via objc2-metal), winit (window), RTP (custom implementation per RFC 6184).

```rust
// src/transport/rtp.rs

#[derive(Debug, Clone, PartialEq)]
pub struct RtpHeader {
    pub version: u8,
    pub padding: bool,
    pub extension: bool,
    pub marker: bool,
    pub payload_type: u8,
    pub sequence_number: u16,
    pub timestamp: u32,
    pub ssrc: u32,
}

impl RtpHeader {
    pub const SIZE: usize = 12;

    pub fn serialize(&self) -> [u8; 12] {
        let mut buf = [0u8; 12];
        buf[0] = (self.version << 6)
            | ((self.padding as u8) << 5)
            | ((self.extension as u8) << 4);
        buf[1] = ((self.marker as u8) << 7) | (self.payload_type & 0x7F);
        buf[2..4].copy_from_slice(&self.sequence_number.to_be_bytes());
        buf[4..8].copy_from_slice(&self.timestamp.to_be_bytes());
        buf[8..12].copy_from_slice(&self.ssrc.to_be_bytes());
        buf
    }

    pub fn parse(buf: &[u8]) -> Option<Self> {
        if buf.len() < 12 {
            return None;
        }
        Some(Self {
            version: (buf[0] >> 6) & 0x03,
            padding: (buf[0] >> 5) & 0x01 == 1,
            extension: (buf[0] >> 4) & 0x01 == 1,
            marker: (buf[1] >> 7) & 0x01 == 1,
            payload_type: buf[1] & 0x7F,
            sequence_number: u16::from_be_bytes([buf[2], buf[3]]),
            timestamp: u32::from_be_bytes([buf[4], buf[5], buf[6], buf[7]]),
            ssrc: u32::from_be_bytes([buf[8], buf[9], buf[10], buf[11]]),
        })
    }
}

#[derive(Debug, Clone)]
pub struct RtpPacket {
    pub header: RtpHeader,
    pub payload: Vec<u8>,
}

impl RtpPacket {
    pub fn serialize(&self) -> Vec<u8> {
        let header_bytes = self.header.serialize();
        let mut buf = Vec::with_capacity(12 + self.payload.len());
        buf.extend_from_slice(&header_bytes);
        buf.extend_from_slice(&self.payload);
        buf
    }

    pub fn parse(buf: &[u8]) -> Option<Self> {
        let header = RtpHeader::parse(buf)?;
        let payload = buf[12..].to_vec();
        Some(Self { header, payload })
    }
}
```

```rust
use screen_mirror::transport::rtp::{H264Packetizer, H264Depacketizer};

#[test]
fn test_single_nal_unit_no_fragmentation() {
    let mut packetizer = H264Packetizer::new(96, 0xAABBCCDD, 1400);
    // Small NAL unit (< MTU)
    let nal = vec![0x65; 100]; // IDR slice, 100 bytes
    let packets = packetizer.packetize(&nal, 90000);
    assert_eq!(packets.len(), 1);
    assert_eq!(packets[0].header.payload_type, 96);
    assert_eq!(packets[0].header.timestamp, 90000);
    assert_eq!(packets[0].header.marker, true);
    assert_eq!(packets[0].payload, nal);
}

#[test]
fn test_large_nal_fua_fragmentation() {
    let mut packetizer = H264Packetizer::new(96, 0xAABBCCDD, 1400);
    // Large NAL unit (> MTU, needs FU-A)
    let nal = vec![0x65; 5000]; // 5000 bytes IDR
    let packets = packetizer.packetize(&nal, 90000);
    // 5000 / (1400 - 12 - 2) = ~4 fragments (MTU - RTP header - FU-A header)
    assert!(packets.len() >= 4);
    // Only last packet has marker bit
    for pkt in &packets[..packets.len() - 1] {
        assert_eq!(pkt.header.marker, false);
    }
    assert_eq!(packets.last().unwrap().header.marker, true);
    // All same timestamp
    for pkt in &packets {
        assert_eq!(pkt.header.timestamp, 90000);
    }
}

#[test]
fn test_fua_roundtrip() {
    let mut packetizer = H264Packetizer::new(96, 0xAABBCCDD, 1400);
    let mut depacketizer = H264Depacketizer::new();

    let original_nal = vec![0x65; 5000];
    let packets = packetizer.packetize(&original_nal, 90000);

    for pkt in &packets {
        depacketizer.push(pkt);
    }
    let reassembled = depacketizer.pop_nal().unwrap();
    assert_eq!(reassembled, original_nal);
}
```

```rust
// append to src/transport/rtp.rs

pub struct H264Packetizer {
    payload_type: u8,
    ssrc: u32,
    max_payload: usize,
    sequence_number: u16,
}

impl H264Packetizer {
    pub fn new(payload_type: u8, ssrc: u32, mtu: usize) -> Self {
        Self {
            payload_type,
            ssrc,
            max_payload: mtu - RtpHeader::SIZE,
            sequence_number: 0,
        }
    }

    pub fn packetize(&mut self, nal: &[u8], timestamp: u32) -> Vec<RtpPacket> {
        if nal.len() <= self.max_payload {
            self.single_nal(nal, timestamp)
        } else {
            self.fragment_fua(nal, timestamp)
        }
    }

    fn next_seq(&mut self) -> u16 {
        let seq = self.sequence_number;
        self.sequence_number = self.sequence_number.wrapping_add(1);
        seq
    }

    fn single_nal(&mut self, nal: &[u8], timestamp: u32) -> Vec<RtpPacket> {
        vec![RtpPacket {
            header: RtpHeader {
                version: 2,
                padding: false,
                extension: false,
                marker: true,
                payload_type: self.payload_type,
                sequence_number: self.next_seq(),
                timestamp,
                ssrc: self.ssrc,
            },
            payload: nal.to_vec(),
        }]
    }

    fn fragment_fua(&mut self, nal: &[u8], timestamp: u32) -> Vec<RtpPacket> {
        let nal_header = nal[0];
        let nal_type = nal_header & 0x1F;
        let nri = nal_header & 0x60;
        let data = &nal[1..]; // skip NAL header byte

        let fua_max = self.max_payload - 2; // 2 bytes for FU indicator + FU header
        let mut packets = Vec::new();
        let mut offset = 0;

        while offset < data.len() {
            let end = (offset + fua_max).min(data.len());
            let is_start = offset == 0;
            let is_end = end == data.len();

            let fu_indicator = 28 | nri; // FU-A type = 28
            let fu_header = ((is_start as u8) << 7)
                | ((is_end as u8) << 6)
                | nal_type;

            let mut payload = Vec::with_capacity(2 + (end - offset));
            payload.push(fu_indicator);
            payload.push(fu_header);
            payload.extend_from_slice(&data[offset..end]);

            packets.push(RtpPacket {
                header: RtpHeader {
                    version: 2,
                    padding: false,
                    extension: false,
                    marker: is_end,
                    payload_type: self.payload_type,
                    sequence_number: self.next_seq(),
                    timestamp,
                    ssrc: self.ssrc,
                },
                payload,
            });
            offset = end;
        }
        packets
    }
}

pub struct H264Depacketizer {
    buffer: Vec<u8>,
    in_fragment: bool,
}

impl H264Depacketizer {
    pub fn new() -> Self {
        Self {
            buffer: Vec::new(),
            in_fragment: false,
        }
    }

    pub fn push(&mut self, packet: &RtpPacket) {
        if packet.payload.is_empty() {
            return;
        }
        let first_byte = packet.payload[0];
        let nal_type = first_byte & 0x1F;

        if nal_type == 28 {
            // FU-A
            if packet.payload.len() < 2 {
                return;
            }
            let fu_header = packet.payload[1];
            let is_start = (fu_header >> 7) & 1 == 1;
            let original_type = fu_header & 0x1F;
            let nri = first_byte & 0x60;

            if is_start {
                self.buffer.clear();
                self.buffer.push(nri | original_type); // reconstruct NAL header
                self.in_fragment = true;
            }
            if self.in_fragment {
                self.buffer.extend_from_slice(&packet.payload[2..]);
            }
        } else {
            // Single NAL unit
            self.buffer = packet.payload.clone();
            self.in_fragment = false;
        }
    }

    pub fn pop_nal(&mut self) -> Option<Vec<u8>> {
        if self.buffer.is_empty() {
            None
        } else {
            Some(std::mem::take(&mut self.buffer))
        }
    }
}
```

```rust
use std::net::{UdpSocket, SocketAddr};
use anyhow::Result;

pub struct UdpSender {

    target: SocketAddr,
}

impl UdpSender {
    pub fn new(target: SocketAddr) -> Result<Self> {
        let socket = UdpSocket::bind("0.0.0.0:0")?;
        Ok(Self { socket, target })
    }

    pub fn send(&self, data: &[u8]) -> Result<()> {
        self.socket.send_to(data, self.target)?;
        Ok(())
    }
}

pub struct UdpReceiver {
    socket: UdpSocket,
}

impl UdpReceiver {
    pub fn new(bind_addr: SocketAddr) -> Result<Self> {
        let socket = UdpSocket::bind(bind_addr)?;
        Ok(Self { socket })
    }

    pub fn recv(&self, buf: &mut [u8]) -> Result<usize> {
        let (n, _addr) = self.socket.recv_from(buf)?;
        Ok(n)
    }

    pub fn set_nonblocking(&self, nonblocking: bool) -> Result<()> {
        self.socket.set_nonblocking(nonblocking)?;
        Ok(())
    }
}
```

```rust
// src/capture/macos.rs
use anyhow::Result;
use screencapturekit::{
    sc_shareable_content::SCShareableContent,
    sc_stream::SCStream,
    sc_stream_configuration::SCStreamConfiguration,
    sc_content_filter::SCContentFilter,
    sc_output_handler::{SCStreamOutputType, StreamOutput},
    cm_sample_buffer::CMSampleBuffer,
};
use std::sync::mpsc;

use super::CaptureConfig;

pub struct MacOsCapture {
    stream: Option<SCStream>,
    rx: mpsc::Receiver<CMSampleBuffer>,
}

struct OutputHandler {
    tx: mpsc::SyncSender<CMSampleBuffer>,
}

impl StreamOutput for OutputHandler {
    fn did_output_sample_buffer(
        &self,
        sample_buffer: CMSampleBuffer,
        _of_type: SCStreamOutputType,
    ) {
        let _ = self.tx.try_send(sample_buffer);
    }
}

impl MacOsCapture {
    pub fn new(config: CaptureConfig) -> Result<Self> {
        let content = SCShareableContent::current();
        let display = content
            .displays
            .into_iter()
            .next()
            .ok_or_else(|| anyhow::anyhow!("no display found"))?;

        let filter = SCContentFilter::new().with_display_excluding_windows(display, &[]);

        let mut stream_config = SCStreamConfiguration::new();
        stream_config.set_width(config.width);
        stream_config.set_height(config.height);
        stream_config.set_minimum_frame_interval(core_media::CMTime {
            value: 1,
            timescale: config.fps as i32,
            flags: 0,
            epoch: 0,
        });
        stream_config.set_pixel_format(875704438); // kCVPixelFormatType_32BGRA
        stream_config.set_shows_cursor(true);

        let (tx, rx) = mpsc::sync_channel(2);
        let handler = OutputHandler { tx };

        let mut stream = SCStream::new(filter, stream_config, handler);
        stream.start_capture()?;

        Ok(Self {
            stream: Some(stream),
            rx,
        })
    }

    pub fn next_frame(&self) -> Option<CMSampleBuffer> {
        self.rx.recv().ok()
    }
}

impl Drop for MacOsCapture {
    fn drop(&mut self) {
        if let Some(mut stream) = self.stream.take() {
            let _ = stream.stop_capture();
        }
    }
}
```

```rust
use tracing_subscriber::EnvFilter;

fn main() -> Result<()> {
    tracing_subscriber::fmt()
        .with_env_filter(EnvFilter::from_default_env())
        .init();

    let target: SocketAddr = std::env::args()
        .nth(1)
        .unwrap_or_else(|| "127.0.0.1:5004".to_string())
        .parse()?;

    tracing::info!("sender starting, target={target}");

    let capture = MacOsCapture::new(CaptureConfig {
        fps: 60,
        width: 1920,
        height: 1080,
    })?;

    let mut encoder = VTEncoder::new(EncoderConfig {
        width: 1920,
        height: 1080,
        fps: 60,
        bitrate: 10_000_000, // 10 Mbps
    })?;

    let mut packetizer = H264Packetizer::new(96, 0x12345678, 1400);
    let udp = UdpSender::new(target)?;

    let mut frame_count: u64 = 0;

    loop {
        let Some(sample_buffer) = capture.next_frame() else {
            continue;
        };

        // Extract CVPixelBuffer from CMSampleBuffer and encode
        // (exact API depends on screencapturekit crate version)
        encoder.encode_pixel_buffer(/* pixel_buffer_ptr */, frame_count)?;
        frame_count += 1;

        // Drain encoded packets
        while let Some(encoded) = encoder.next_encoded() {
            let timestamp = (encoded.timestamp as u32).wrapping_mul(90); // 90kHz clock
            for nal in &encoded.nal_units {
                let rtp_packets = packetizer.packetize(nal, timestamp);
                for pkt in &rtp_packets {
                    let bytes = pkt.serialize();
                    udp.send(&bytes)?;
                }
            }
        }
    }
}
```

```rust
// src/bin/receiver.rs
use anyhow::Result;
use std::net::SocketAddr;
use tracing_subscriber::EnvFilter;
use winit::event::{Event, WindowEvent};
use winit::event_loop::EventLoop;
use winit::window::WindowBuilder;

use screen_mirror::transport::rtp::{RtpPacket, H264Depacketizer};
use screen_mirror::transport::udp::UdpReceiver;
use screen_mirror::decode::DecoderConfig;
use screen_mirror::decode::videotoolbox::VTDecoder;
use screen_mirror::render::metal::MetalRenderer;

fn main() -> Result<()> {
    tracing_subscriber::fmt()
        .with_env_filter(EnvFilter::from_default_env())
        .init();

    let bind: SocketAddr = std::env::args()
        .nth(1)
        .unwrap_or_else(|| "0.0.0.0:5004".to_string())
        .parse()?;

    tracing::info!("receiver starting, listening on {bind}");

    let udp = UdpReceiver::new(bind)?;
    udp.set_nonblocking(true)?;

    let mut depacketizer = H264Depacketizer::new();
    let mut decoder = VTDecoder::new(DecoderConfig {
        width: 1920,
        height: 1080,
    })?;

    let event_loop = EventLoop::new()?;
    let window = WindowBuilder::new()
        .with_title("Screen Mirror Receiver")
        .with_inner_size(winit::dpi::LogicalSize::new(1920, 1080))
        .build(&event_loop)?;

    let mut renderer = MetalRenderer::new(&window)?;

    let mut recv_buf = vec![0u8; 2000];
    let mut last_seq: Option<u16> = None;

    event_loop.run(move |event, elwt| {
        match event {
            Event::WindowEvent { event: WindowEvent::CloseRequested, .. } => {
                elwt.exit();
            }
            Event::AboutToWait => {
                // Poll UDP packets
                loop {
                    match udp.recv(&mut recv_buf) {
                        Ok(n) => {
                            if let Some(pkt) = RtpPacket::parse(&recv_buf[..n]) {
                                // Track sequence for loss detection
                                if let Some(prev) = last_seq {
                                    let expected = prev.wrapping_add(1);
                                    if pkt.header.sequence_number != expected {
                                        tracing::warn!(
                                            "packet loss: expected {expected}, got {}",
                                            pkt.header.sequence_number
                                        );
                                    }
                                }
                                last_seq = Some(pkt.header.sequence_number);

                                depacketizer.push(&pkt);

                                // If marker bit set, NAL is complete
                                if pkt.header.marker {
                                    if let Some(nal) = depacketizer.pop_nal() {
                                        let ts = pkt.header.timestamp as u64;
                                        let _ = decoder.decode_nal(&nal, ts);
                                    }
                                }
                            }
                        }
                        Err(ref e) if e.kind() == std::io::ErrorKind::WouldBlock => break,
                        Err(e) => {
                            tracing::error!("recv error: {e}");
                            break;
                        }
                    }
                }

                // Render latest decoded frame
                if let Some(frame) = decoder.next_frame() {
                    let _ = renderer.render_pixel_buffer(frame.pixel_buffer);
                }

                window.request_redraw();
            }
            _ => {}
        }
    })?;

    Ok(())
}
```

## Notes for Implementer

1. **screencapturekit-rs API**: The crate API may differ from the code above. Check `https://docs.rs/screencapturekit` for current version. The key flow is: create SCStream → receive CMSampleBuffer in callback → extract CVPixelBuffer.

2. **VideoToolbox FFI**: This is the hardest part. Consider using the `video-toolbox-sys` crate or writing raw FFI with `objc2`. The encoder callback receives `CMSampleBuffer` which must be parsed for H.264 parameter sets (SPS/PPS) and slice NAL units.

3. **macOS Permissions**: Screen recording requires the app to be added to System Preferences → Privacy & Security → Screen Recording. Running from `cargo run` may require adding the terminal app.

4. **Pixel Format**: ScreenCaptureKit outputs BGRA by default. VideoToolbox encoder accepts BGRA or NV12. If using BGRA, set `kCVPixelFormatType_32BGRA` (875704438). For better performance, configure ScreenCaptureKit to output `kCVPixelFormatType_420YpCbCr8BiPlanarVideoRange` (420v).

5. **Zero-copy path**: The ideal path is ScreenCaptureKit → CMSampleBuffer → CVPixelBuffer → VTCompressionSession (encode) → all in GPU memory. Avoid calling `CVPixelBufferLockBaseAddress` which forces a GPU→CPU copy.
