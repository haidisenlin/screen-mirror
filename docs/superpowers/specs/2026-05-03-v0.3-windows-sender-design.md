# v0.3 — Windows 发送端 设计文档

## 目标

发送端支持 Windows 10+，验证跨平台 trait 抽象。Windows 发送 → macOS 接收，1080p@30fps+ 流畅（标准屏 60fps），编码器自动探测（NVENC → MF → x264）。

## 架构概览

建立 `VideoCapture` / `AudioCapture` trait 抽象层，macOS 和 Windows 各自实现。Encoder 为具体 struct + `#[cfg]` 条件编译 + 运行时优先级探测。

```
┌─────────────────────────────────────────────────────┐
│                    sender.rs                         │
│   (cfg 选择平台 capture/encoder 实现)                │
└────────┬──────────────────────────────┬─────────────┘
         │                              │
    VideoCapture trait             AudioCapture trait
         │                              │
  ┌──────┴──────┐               ┌──────┴──────┐
  │macOS: SCK   │               │macOS: SCK   │
  │Win: DXGI    │               │Win: WASAPI  │
  └──────┬──────┘               └─────────────┘
         │
         ▼
  ┌─────────────────────┐
  │   VideoEncoder      │
  │  (具体 struct)       │
  ├─────────────────────┤
  │ macOS: VideoToolbox │
  │ Win: NVENC→MF→x264  │
  └─────────────────────┘
```

## 技术选型

### 屏幕捕获：DXGI Desktop Duplication

- **API**：`IDXGIOutputDuplication::AcquireNextFrame()`
- **输出**：`ID3D11Texture2D`（BGRA8，GPU 纹理）
- **最低版本**：Windows 10（全版本）
- **依赖**：`windows` crate（微软官方 Rust 绑定）
- **光标**：捕获阶段通过 `GetFramePointerShape()` 获取，编码前合成到帧内

### 视频编码：运行时优先级探测

| 优先级 | 编码器 | 延迟 | 依赖 |
|--------|--------|------|------|
| 1 | NVENC | ~5ms | `nvcodec` crate |
| 2 | Media Foundation HW MFT | ~8ms | `windows` crate |
| 3 | x264 软件 | ~40ms | `x264` crate |

- **输入格式**：NV12（通过 D3D11 compute shader 从 BGRA 转换）
- **Profile**：H.264 High Profile
- **探测时机**：启动时按优先级依次尝试创建 session，首个成功的即为当次运行编码器

### 格式转换：GPU BGRA→NV12

- **方式**：D3D11 Compute Shader
- **时机**：每帧捕获后、编码前
- **开销**：<1ms（GPU 上执行）
- **参考**：NVIDIA `nvEncDXGIOutputDuplicationSample` 中的 `RGBToNV12` 实现

### 音频捕获：WASAPI Loopback

- **API**：`IAudioClient` + `AUDCLNT_STREAMFLAGS_LOOPBACK`（Shared Mode）
- **轮询方式**：Timer polling（不用 event callback，避开 Windows flag 冲突）
- **格式**：48kHz / f32 / stereo（`AUDCLNT_STREAMFLAGS_AUTOCONVERTPCM` 自动转换）
- **设备变更**：`IMMNotificationClient` 监听热插拔
- **依赖**：`windows` crate 直接调用 COM API
- **参考**：Sunshine `audio.cpp` 实现模式

## Trait 定义

```rust
// src/capture/mod.rs

pub struct CaptureConfig {
    pub fps: u32,
    pub width: u32,
    pub height: u32,
}

#[cfg(target_os = "macos")]
pub type NativeFrame = *mut std::ffi::c_void; // CVPixelBufferRef

#[cfg(target_os = "windows")]
pub type NativeFrame = *mut std::ffi::c_void; // ID3D11Texture2D

pub struct CapturedFrame {
    pub native: NativeFrame,
    pub timestamp_ns: u64,
}

pub trait VideoCapture {
    fn new(config: &CaptureConfig) -> anyhow::Result<Self> where Self: Sized;
    fn width(&self) -> u32;
    fn height(&self) -> u32;
    fn next_frame(&self) -> Option<CapturedFrame>;
}

pub trait AudioCapture {
    fn new(sample_rate: u32, channels: u16) -> anyhow::Result<Self> where Self: Sized;
    fn try_next_audio(&self) -> Option<Vec<f32>>;
}
```

## sender.rs 重构

```rust
// 平台选择通过 cfg 在编译期确定
#[cfg(target_os = "macos")]
use screen_mirror::capture::macos::MacOsCapture as PlatformCapture;
#[cfg(target_os = "windows")]
use screen_mirror::capture::windows::DxgiCapture as PlatformCapture;

#[cfg(target_os = "windows")]
use screen_mirror::capture::windows::WasapiCapture as PlatformAudio;

fn main() -> Result<()> {
    let capture = PlatformCapture::new(&config)?;
    let audio = PlatformAudio::new(48000, 2)?;
    let encoder = VideoEncoder::new(&encoder_config)?;
    
    loop {
        if let Some(frame) = capture.next_frame() {
            encoder.encode(&frame)?;
        }
        while let Some(pcm) = audio.try_next_audio() {
            // Opus encode + send
        }
    }
}
```

## macOS 适配

现有 `MacOsCapture` 需要拆分为 `VideoCapture` + `AudioCapture` 两个 trait 实现。当前 SCK 同时提供视频和音频，拆分方式：

- `MacOsVideoCapture`：实现 `VideoCapture`，内部持有 SCK stream + video channel
- `MacOsAudioCapture`：实现 `AudioCapture`，持有 audio channel（从同一 SCK stream）
- 共享 `SCStream` 实例通过 `Arc` 传递

## 验收标准

1. **Windows 发送 → macOS 接收**：1080p@30fps+ 流畅显示（高分屏 30fps，标准屏 60fps）
2. **编码器自动探测**：NVENC（NVIDIA）→ MF（Intel/AMD）→ x264（无独显），启动日志显示选择结果
3. **音频**：WASAPI loopback 捕获 → Opus → 接收端正常播放
4. **macOS 不回归**：现有 macOS sender/receiver 功能不受影响
5. **交叉编译**：`cargo build --target x86_64-pc-windows-msvc` 在 macOS 上编译通过（MinGW）
