# Receiver /verify-pin HTTP 端点设计

**版本:** v0.51（基于 v0.5 主分支迭代）

## 概述

Receiver 启动时额外监听一个 HTTP 端口，响应 sender 的 `POST /verify-pin` 请求。通过 mDNS TXT record 广播该端口，sender 从发现结果中获取 HTTP 端口进行 PIN 验证。遵循 Sunshine 模式（控制端口与数据端口分离）。

## 动机

Sender 的 PIN 验证流程需要一个 HTTP 端点来查询 receiver 的 PIN 是否匹配。当前 receiver 只有 TCP 配对监听，无法响应 HTTP 请求。

## 架构

```
Receiver 启动:
  1. 生成 6 位 PIN
  2. bind HTTP server (0.0.0.0:0 → 系统分配端口)
  3. bind TCP pairing listener
  4. mDNS 广播: service + TXT { http_port=XXXX }
  5. 打印 PIN 到终端/UI

Sender 发现 receiver:
  Browser 解析 mDNS → DiscoveredReceiver { addr, http_port }

Sender PIN 验证:
  POST http://{ip}:{http_port}/verify-pin → 200/403
```

## 1. Receiver HTTP Server

### 技术选型

使用 `tiny_http` crate：
- 纯 Rust，零外部依赖
- 同步阻塞 API，适合单线程处理
- 最小化二进制体积影响

### 接口定义

- 路径：`POST /verify-pin`
- Request body：`{"pin": "123456"}`
- 匹配成功：`200 {"device_name": "客厅电视"}`
- 不匹配：`403 {}`
- 其他路径/方法：`404`

### 生命周期

- 在独立线程运行，接收 `Arc<AtomicBool>` 控制退出
- 与主配对循环互不阻塞
- PIN 通过 `Arc<Mutex<String>>` 共享（配对成功后 PIN 可能刷新）
- 设备名通过参数传入

## 2. mDNS Advertiser 变更

当前签名：
```rust
pub fn new(device_name: &str) -> Result<(Self, TcpListener)>
```

变更后：
```rust
pub fn new(device_name: &str, http_port: u16) -> Result<(Self, TcpListener)>
```

注册 service 时添加 TXT record：
```
http_port={port}
```

## 3. mDNS Browser 变更

### DiscoveredReceiver 结构体

```rust
pub struct DiscoveredReceiver {
    pub name: String,
    pub addr: SocketAddr,
    pub http_port: Option<u16>,
}
```

`http_port` 为 `Option<u16>`：兼容不支持 verify-pin 的旧版 receiver。

### 解析逻辑

Browser 解析 mDNS 响应时，读取 TXT record 中的 `http_port` 字段：
```rust
let http_port = txt_properties.get("http_port")
    .and_then(|v| v.parse::<u16>().ok());
```

## 4. Sender handle_verify_pin 变更

```rust
fn handle_verify_pin(...) {
    for device in devices {
        let port = device.http_port.unwrap_or(device.addr.port());
        let url = format!("http://{}:{}/verify-pin", device.addr.ip(), port);
        // ... 发送请求
    }
}
```

当 `http_port` 为 `None`（旧版 receiver）时，降级使用配对端口（请求会失败，但不会崩溃）。

## 5. 文件变更清单

| 文件 | 变更 |
|------|------|
| `Cargo.toml` | 添加 `tiny_http` 依赖 |
| `src/discovery/advertiser.rs` | `new()` 接受 http_port，注册 TXT record |
| `src/discovery/browser.rs` | DiscoveredReceiver 增加 http_port，解析 TXT |
| `src/bin/receiver.rs` | 生成 PIN、启动 HTTP server 线程、传 http_port 给 Advertiser |
| `src/ui/backend.rs` | handle_verify_pin 使用 device.http_port |

## 6. 不在范围内

- HTTPS（局域网信任环境）
- Rate limiting
- PIN 过期/刷新机制
- Receiver 端 UI（当前终端打印 PIN）
