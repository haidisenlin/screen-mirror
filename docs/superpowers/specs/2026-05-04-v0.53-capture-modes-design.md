# v0.53 Capture Modes Design

> 全屏镜像 / 选择窗口 / 自定义区域 三种屏幕捕获模式

## Goal

在 sender 端实现三种捕获模式选择，使用户可以选择全屏、特定窗口或自定义屏幕区域进行镜像传输。

## Platform Scope

| 平台 | 全屏 | 窗口 | 区域 |
|------|:----:|:----:|:----:|
| macOS | ✅ | ✅ | ✅ |
| Windows | ✅ | ✅ | ✅ |
| Linux | ✅ | ❌ | ❌ |

## Architecture

### 数据模型

```rust
pub struct WindowInfo {
    pub id: u64,                    // CGWindowID(u32) 或 HWND(u64)
    pub title: String,
    pub app_name: String,
}

pub enum CaptureMode {
    FullScreen,
    Window { id: u64, title: String },
    Region { x: f64, y: f64, width: f64, height: f64 },  // 逻辑坐标
}
```

### 消息定义

```rust
pub enum UiCommand {
    // ...existing...
    StartStreaming { mode: CaptureMode },  // mode 字段真正生效
    ListWindows,
}

pub enum BackendEvent {
    // ...existing...
    WindowList(Vec<WindowInfo>),
    CaptureTargetLost { reason: String },
}
```

### Capture Trait

```rust
pub enum CaptureError {
    TargetLost,
    PermissionDenied,
    DeviceError(String),
}

pub struct CaptureConfig {
    pub mode: CaptureMode,
    pub fps: u32,
    pub width: u32,
    pub height: u32,
}

pub trait VideoCapture {
    fn new(config: &CaptureConfig) -> Result<Self> where Self: Sized;
    fn width(&self) -> u32;
    fn height(&self) -> u32;
    fn next_frame(&self) -> Result<Option<CapturedFrame>, CaptureError>;
}
```

`next_frame()` 返回：
- `Ok(Some(frame))` — 新帧
- `Ok(None)` — 暂无新帧（timeout），正常重试
- `Err(CaptureError::TargetLost)` — 目标丢失，需要重建

### 平台分发

编译时 `#[cfg]` 分发（scap/Cap 模式）：

```rust
#[cfg(target_os = "macos")]
pub use macos::MacOsCapture as PlatformCapture;

#[cfg(target_os = "windows")]
pub use windows::WindowsCapture as PlatformCapture;

#[cfg(target_os = "linux")]
pub use linux::LinuxCapture as PlatformCapture;
```

Windows 内部运行时 enum 分发（Sunshine 模式）：

```rust
pub struct WindowsCapture { inner: CaptureInner }

enum CaptureInner {
    Dxgi(DxgiCapture),   // 全屏 + 区域
    Wgc(WgcCapture),     // 窗口
}
```

### macOS 捕获路径

| 模式 | SCContentFilter | SCStreamConfiguration |
|------|----------------|----------------------|
| FullScreen | `with_display(&display).with_excluding_windows(&[])` | 标准配置 |
| Window | `with_window(&window)` | `with_ignores_shadows_single_window(true)` |
| Region | `with_display(&display).with_excluding_windows(&[])` | `with_source_rect(CGRect)` 硬件裁剪 |

### Windows 捕获路径

| 模式 | API | 裁剪方式 |
|------|-----|---------|
| FullScreen | DXGI Desktop Duplication | 无 |
| Window | WGC `CreateForWindow(HWND)` | 无 |
| Region | DXGI Desktop Duplication | `CopySubresourceRegion(D3D11_BOX)` GPU 裁剪，编码前 |

Windows 全屏捕获预留 WGC 回退路径（应对 Windows 11 24H2 兼容性问题）。

### 窗口枚举

```rust
pub fn list_windows() -> Result<Vec<WindowInfo>>
```

- macOS: `SCShareableContent::get().windows()` — 过滤 `is_on_screen() && window_layer() == 0`
- Windows: `EnumWindows` + `IsWindowVisible` + `GetWindowTextLength > 0` — 排除自身窗口
- Linux: 返回空列表

### 音频

- macOS: SCK 音视频一体（`captures_audio = true`），窗口模式捕获所属应用的全部音频
- Windows: 音频独立于 VideoCapture，通过 WASAPI loopback 捕获（WGC 不提供音频）

## 区域选择 Overlay

### 方案

"截图冻结"模式（Flameshot/ShareX/Windows Snipping Tool 验证过的方案）：

1. 截取全屏快照
2. egui 窗口全屏化（手动 resize，不用 `Fullscreen(true)` 避免平台 bug）
3. 画截图作为底图 + 半透明暗色遮罩
4. 用户拖拽选区（亮区 + 边框 + 尺寸标注）
5. Enter 确认 / Esc 取消
6. 窗口恢复原状，返回坐标

### 技术实现

复用 egui 事件循环（非独立窗口/进程），作为 App 的一个视图状态：

```rust
pub struct RegionSelectView {
    screenshot: egui::ColorImage,
    texture: Option<egui::TextureHandle>,
    state: RegionSelectState,
}

enum RegionSelectState {
    Idle,
    Dragging { start: Pos2, current: Pos2 },
    Selected { rect: Rect },  // 可 resize，等待确认
}

pub enum RegionAction {
    None,
    Confirmed(SelectedRegion),
    Cancelled,
}
```

渲染方式（region-to-share 验证过的 egui 方案）：
- `CentralPanel` 画截图纹理
- `painter().rect_filled()` 画暗色遮罩
- `allocate_rect(Sense::click_and_drag())` 处理拖拽
- `painter().rect_stroke()` 画选区边框

### 截图获取

- macOS: `CGDisplayCreateImage(CGMainDisplayID())` — 同步，5-15ms
- Windows: `BitBlt` from desktop DC — 同步
- Linux: `XGetImage` / XCB SHM

### 全屏化方式

```rust
// 进入区域选择
ctx.send_viewport_cmd(ViewportCommand::Decorations(false));
ctx.send_viewport_cmd(ViewportCommand::InnerSize(screen_size));
ctx.send_viewport_cmd(ViewportCommand::OuterPosition(Pos2::ZERO));

// 退出区域选择
ctx.send_viewport_cmd(ViewportCommand::Decorations(true));
ctx.send_viewport_cmd(ViewportCommand::InnerSize(original_size));
```

## UI 视图状态机

```
Idle → [PIN匹配成功] → ModeSelect → FullScreen → Streaming
                                   → Window → [ListWindows → 选择] → Streaming
                                   → Region → [RegionSelect → 确认] → Streaming

Streaming → CaptureTargetLost → ModeSelect (toast 提示原因)
```

### AppView Enum

```rust
pub enum AppView {
    Idle,
    ModeSelect,
    RegionSelect,
    Streaming,
}
```

### Session Generation

防止旧捕获会话事件污染新会话（RustDesk ConnectionRoundState 模式）：

```rust
pub struct App {
    session_gen: u64,  // 每次回到 ModeSelect 递增
}
```

### ModeView 修改

三个按钮全部启用：
- 🖥️ 全屏镜像 → `StartStreaming { FullScreen }`
- 🪟 选择窗口 → `ListWindows` → 显示窗口列表 → 用户选择
- ⬜ 自定义区域 → 进入 RegionSelect 视图

窗口列表：文字列表（app_name + title），v0.53 不含缩略图。

### Toast 通知

使用 `egui-toast` crate 显示 CaptureTargetLost 原因，5 秒自动消失。

## 协商流程

`negotiate()` 根据 CaptureMode 确定 offer 分辨率：

| 模式 | 分辨率来源 |
|------|-----------|
| FullScreen | `native_resolution()` 现有逻辑 |
| Window | 查询窗口尺寸（macOS: `SCWindow.frame()`，Windows: `GetWindowRect`） |
| Region | 直接使用选区 width × height |
