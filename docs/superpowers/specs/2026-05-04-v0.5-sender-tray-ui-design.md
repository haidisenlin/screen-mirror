# v0.5 系统托盘 UI 发送端设计规格

## 目标

将当前 CLI sender 改造为系统托盘应用，通过 Popover 面板提供设备发现、PIN 配对、投屏模式选择、实时状态监控和投屏控制功能。

## 技术选型

| 组件 | 方案 | 依据 |
|------|------|------|
| 系统托盘 | `tray-icon` crate | 官方有 egui 示例；TeamViewer/向日葵/RustDesk 均用原生托盘 API |
| GUI 框架 | `egui` (eframe 0.34.0+) | 官方 tray-icon 集成验证；Visible(bool) 支持 show/hide；30MB 内存 |
| 窗口行为 | Popover（无边框 + 置顶 + focus-lost 隐藏） | macOS AirPlay 模式；4/4 竞品用 show/hide 非 create/destroy |
| 状态管理 | Rust enum 状态机 | Fowler ECOOP 2020 证明 MVU 正确性；编译期保证状态转换合法 |
| 异步通信 | mpsc channel（后台线程 → egui try_recv） | 标准 Rust 异步模式 |

### 排除方案及理由

| 排除方案 | 理由 |
|----------|------|
| wry/WebView | Microsoft 官方不推荐简单面板用 WebView；向日葵/RustDesk 明确拒绝 WebView |
| iced | 无 set_visible API（只能 open/close）；无官方 tray-icon 示例；零生产验证 |
| Flutter | 对简单面板过重（需 Dart 运行时 + FFI）；RustDesk 团队称 Flutter 桌面"worse than expected" |
| 持久浮动窗口 | 我们是 caster（非 presenter），用户投屏后继续工作，不需要持久占屏 |

## 状态机

```
enum AppState {
    Idle {
        devices: Vec<DiscoveredReceiver>,
        selected_device: Option<usize>,
        pin_input: String,
        error: Option<String>,
    },
    Connecting {
        device_name: String,
    },
    ModeSelect {
        device_name: String,
    },
    Streaming {
        device_name: String,
        stats: StreamStats,
    },
    Paused {
        device_name: String,
        stats: StreamStats,
    },
}
```

状态转换：

```
Idle ──[连接按钮]──▶ Connecting
Connecting ──[配对成功]──▶ ModeSelect
Connecting ──[配对失败]──▶ Idle (显示错误)
Connecting ──[超时 10s]──▶ Idle (显示"连接超时")
ModeSelect ──[开始投屏]──▶ Streaming
Streaming ──[暂停]──▶ Paused
Streaming ──[断开]──▶ Idle
Streaming ──[连接断开]──▶ Idle (显示"连接已断开")
Paused ──[恢复]──▶ Streaming
Paused ──[断开]──▶ Idle
```

## 模块设计

### 1. 系统托盘 (tray)

**图标格式：**
- macOS：使用 template image（单色 PNG，系统自动适配明暗模式）
- Windows：使用 32x32 RGBA PNG 图标

**图标状态：**
- 灰色/正常：空闲，无活跃连接（macOS template 默认颜色）
- 绿色填充：投屏中
- 黄色填充：已暂停

**点击行为：**
- 左键单击：切换面板可见性（Visible toggle）
- 面板失去焦点：自动隐藏（Visible(false)）

**图标位置获取：**
- `TrayIconEvent::Click { rect, .. }` 提供图标屏幕坐标
- 面板定位在 rect 正下方（macOS）或正上方（Windows，托盘在底部）

### 2. Popover 窗口

**窗口属性：**
```rust
ViewportBuilder::default()
    .with_decorations(false)
    .with_always_on_top()
    .with_transparent(true)
    .with_inner_size([320.0, 400.0])
    .with_visible(false)  // 初始隐藏
```

**尺寸：**
- 宽度固定 320px
- 高度自适应内容（最小 200px，最大 480px）

**定位策略：**
- macOS：面板顶部对齐托盘图标底部，水平居中
- Windows：面板底部对齐托盘图标顶部，水平居中
- 屏幕边缘检测：确保面板不超出可见区域

**关闭行为：**
- 检测 `ViewportInfo.focused == Some(false)` → 设置 `Visible(false)`
- 不销毁窗口，保持状态

### 3. Idle 视图（设备发现 + PIN 输入）

**布局：**
```
┌──────────────────────────────┐
│  screen-mirror          [●]  │  ← [●] 状态指示
│  ────────────────────────── │
│  🔍 正在搜索设备...          │  ← mDNS 状态
│                              │
│  ┌────────────────────────┐  │
│  │ 📺 客厅电视   192.168.…│  │  ← 设备列表（可点选）
│  │ 📺 会议室投影 192.168.…│  │
│  └────────────────────────┘  │
│                              │
│  投屏码: [_ _ _ _ _ _]      │  ← 6位数字输入框
│  [连 接]                     │  ← 主操作按钮
│                              │
│  ❌ 投屏码错误，请重试       │  ← 错误提示（条件显示）
└──────────────────────────────┘
```

**功能：**
- mDNS 持续浏览，设备列表实时更新
- 设备条目显示：设备名 + IP 地址
- 点击设备条目选中（高亮），同时光标聚焦到 PIN 输入框
- PIN 输入框仅接受数字，自动限制 6 位
- 连接按钮在选中设备 + 输入 6 位 PIN 后才激活
- 配对失败显示错误信息，3 秒后自动清除

### 4. ModeSelect 视图（投屏模式选择）

**布局：**
```
┌──────────────────────────────┐
│  选择投屏内容                 │
│  ────────────────────────── │
│                              │
│  ┌─────────┐ ┌─────────┐    │
│  │  🖥️     │ │  🪟     │    │  ← 模式卡片（可点选）
│  │ 全屏镜像 │ │ 选择窗口 │    │
│  └─────────┘ └─────────┘    │
│  ┌─────────┐                 │
│  │  ⬜     │                 │
│  │自定义区域│                 │
│  └─────────┘                 │
│                              │
│  ☑ 包含系统音频              │  ← 复选框
│  [开始投屏]                  │  ← 主操作按钮
└──────────────────────────────┘
```

**功能：**
- 三种模式：全屏镜像、选择窗口、自定义区域
- 全屏镜像：直接开始，捕获整个屏幕
- 选择窗口：点击后列出当前打开的窗口列表供选择
- 自定义区域：点击后进入区域选择模式（覆盖屏幕的半透明遮罩，拖拽选择矩形区域）
- 包含系统音频：默认勾选
- v0.5 scope：仅实现全屏镜像。选择窗口和自定义区域作为 disabled 选项展示（标注"即将推出"）

│  ────────────────────────── │
│                              │

│                              │

└──────────────────────────────┘

**功能：**
- 实时统计每 500ms 更新一次
- 统计来源：投屏引擎通过 channel 发送 StreamStats
- 暂停：停止发送新帧（接收端冻结最后一帧），不断开连接
- 断开：发送 disconnect 消息，关闭连接，回到 Idle

**StreamStats 结构：**
```rust

    latency_ms: f32,
    packet_loss_pct: f32,
}
```

### 7. 后台线程通信

**Channel 消息定义：**

```rust
// UI → Backend
enum UiCommand {
    Connect { addr: SocketAddr, pin: String },
    StartStreaming { mode: CaptureMode },
    Pause,
    Resume,
    Disconnect,
}

// Backend → UI
enum BackendEvent {
    DevicesUpdated(Vec<DiscoveredReceiver>),
    PairingSuccess,
    PairingFailed(String),
    PairingTimeout,
    StreamingStarted,
    StatsUpdate(StreamStats),
    Disconnected(String),
}

enum CaptureMode {
    FullScreen,
    // v0.6: Window(WindowId),
    // v0.6: Region { x, y, w, h },
}
```

**线程模型：**
- 主线程：eframe event loop + egui 渲染 + tray-icon 事件
- 后台线程 1：mDNS browser（持续浏览，通过 channel 发送设备更新）
- 后台线程 2：连接/投屏引擎（配对 → Offer/Answer → capture+encode+send loop）

## 窗口管理细节

### show/hide 实现

```rust
// 在 egui update 循环中
fn update(&mut self, ctx: &egui::Context, _frame: &mut eframe::Frame) {
    // 检查 tray 点击事件
    if let Ok(event) = TrayIconEvent::receiver().try_recv() {
        if let TrayIconEvent::Click { rect, .. } = event {
            self.visible = !self.visible;
            if self.visible {
                // 定位窗口
                let pos = calculate_position(rect);
                ctx.send_viewport_cmd(ViewportCommand::OuterPosition(pos));
            }
            ctx.send_viewport_cmd(ViewportCommand::Visible(self.visible));
        }
    }

    // 焦点丢失自动隐藏
    if ctx.input(|i| i.viewport().focused == Some(false)) && self.visible {
        self.visible = false;
        ctx.send_viewport_cmd(ViewportCommand::Visible(false));
    }

    // 渲染当前状态的 UI
    if self.visible {
        self.render_current_state(ctx);
    }
}
```

### 定位计算

```rust
fn calculate_position(icon_rect: tray_icon::Rect) -> egui::Pos2 {
    #[cfg(target_os = "macos")]
    {
        // macOS: 面板在图标下方
        let x = icon_rect.position.x + icon_rect.size.width / 2.0 - PANEL_WIDTH / 2.0;
        let y = icon_rect.position.y + icon_rect.size.height;
        egui::pos2(x as f32, y as f32)
    }
    #[cfg(target_os = "windows")]
    {
        // Windows: 面板在图标上方
        let x = icon_rect.position.x + icon_rect.size.width / 2.0 - PANEL_WIDTH / 2.0;
        let y = icon_rect.position.y - PANEL_HEIGHT;
        egui::pos2(x as f32, y as f32)
    }
}
```

## 与现有代码集成

v0.5 复用 v0.4 的全部安全和协议模块：

| 现有模块 | 用途 |
|----------|------|
| `src/discovery/browser.rs` | mDNS 设备发现 |
| `src/security/pairing.rs` | SPAKE2 配对 |
| `src/security/cipher.rs` | ChaCha20-Poly1305 加密 |

**变更：**
- `src/bin/sender.rs` → 从 CLI 改为 egui 托盘应用（完全重写）
- 新增 `src/ui/` 模块：托盘、面板视图、状态管理
- `src/bin/receiver.rs` 不变
